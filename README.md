
# 🎓 StudentHub - Management Portal

A sleek, lightweight full-stack CRUD application built as an onboarding project. StudentHub provides a modern, interactive UI to manage student records dynamically without the overhead of complex database setups.

---

## Features
* **Full-Stack Application:** Integrated Frontend (HTML/Bootstrap 5) and Backend (Express.js).
* **Modern UI/UX:** Clean, responsive design for easy record management.
* **Interactive Operations:** Add and delete student records directly from the browser in real-time.
* **Zero Database Setup:** Uses a backend in-memory array for instant running and testing.

## Tech Stack
* **Frontend:** HTML5, Vanilla JavaScript, Bootstrap 5
* **Backend:** Node.js, Express.js
